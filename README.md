# Hi, I'm Susmitha

**Technical Product Specialist & Associate PM candidate.**
I read the database schema before the brief, then turn messy real-world constraints into edge-case-proof product specs and interfaces that make sense.

I have a B.Tech in Information Technology. I don't ship production code. I use that foundation to work within system limits, schemas and API boundaries, and to design the states most teams forget: empty, error and loading.

## Case studies

Full write-ups live on [Behance](https://behance.net/susmithrajendr).

- **Data.gov.in Redesign.** Rebuilt the discovery taxonomy and search hierarchy for India's national open data platform. Dense government tables became query-ready dataset cards with metadata previews.
- **E-Shop: Diagnostic Commerce Flow.** An AI-native, conversational shopping flow that replaces the 20-filter search tree, with fallbacks so ambiguous or zero-inventory searches never dead-end.
- **Hospital Outpatient Queue System.** Field research at Thalassery Government Hospital led to a mobile token tracker for patients and a triage dashboard for nursing staff, with fallbacks for non-smartphone users and unstable networks.

## What I've shipped

**[Notey](https://github.com/susmitharajendran45/notey)** is an open-source floating desktop sticky note: borderless, draggable, distraction-free and local-first. I scoped it, designed the interactions, and managed it from first prototype to public release.
